# Análise de Churn: Identificação e Solução para Cancelamento de Assinaturas

## 📌 Sobre o Projeto
Este projeto foi desenvolvido com o objetivo de aplicar conhecimentos de Análise de Dados na prática, aprimorando habilidades analíticas e visão de negócio. Utilizando uma base de dados fornecida em um curso da Hashtag Treinamentos, o foco principal foi investigar um problema real e crítico enfrentado por muitas empresas: a alta taxa de cancelamento de clientes (Churn).

## 🎯 Objetivo
O sistema da empresa estava perdendo muitas assinaturas mensalmente. O objetivo da análise foi identificar, através dos dados, os principais motivos que levavam os clientes a cancelarem seus planos e propor soluções estratégicas e acionáveis para reverter esse cenário e reter os usuários.

## 🛠️ Tecnologias e Ferramentas Utilizadas
- **Python** (Pandas, Matplotlib / Plotly / Seaborn)
- **Jupyter Notebook**
- **Análise Exploratória de Dados (EDA)**

## 📊 Principais Insights e Soluções Propostas

Após a análise detalhada da base de dados, cheguei a três grandes conclusões que estavam impactando diretamente a perda de clientes. Para cada problema identificado, propus uma solução focada no negócio:

### 1. O Problema do Plano Mensal
- **Descoberta:** A taxa de cancelamento entre os clientes que assinavam o plano mensal era de 100%. Todos os clientes desse plano acabavam saindo.
- **Solução Proposta:** Oferecer descontos ou incentivos atrativos para a migração para os planos Anual ou Trimestral, desestimulando a adesão ao plano mensal que não retém o cliente a longo prazo.

### 2. O Gargalo no Call Center
- **Descoberta:** Clientes que precisaram entrar em contato com o Call Center 4 vezes ou mais apresentaram 100% de taxa de cancelamento. A insatisfação gerada pelas repetidas tentativas sem sucesso culminava na saída do cliente.
- **Solução Proposta:** Implementar um alerta no sistema de atendimento e acionar uma equipe de suporte de reforço (ou nível avançado) para assumir e solucionar o problema do usuário a partir da 3ª ligação.

### 3. Atrasos nos Pagamentos
- **Descoberta:** Clientes que acumulavam mais de 20 dias de atraso no pagamento acabavam cancelando a assinatura inevitavelmente.
- **Solução Proposta:** Criar uma política de resolução mais ágil, onde a equipe financeira deve entrar em contato e solucionar o atraso em, no máximo, 10 dias após o vencimento.

## 🚀 Conclusão
Este projeto demonstra como a manipulação e visualização de dados pode ser usada não apenas para gerar gráficos, mas para diagnosticar problemas de negócio complexos e direcionar a tomada de decisão. A aplicação das soluções propostas tem o potencial de reduzir drasticamente a taxa de churn e aumentar o faturamento da empresa.
